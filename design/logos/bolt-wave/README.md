# Bolt Wave variants

Eight takes on `../bolt-wave.svg`, made to answer one question: a lightning bolt on
an audio app is Winamp's territory, so how far does this mark have to move to be
its own?

The resemblance is mostly about colour. Winamp's icon is a yellow-orange bolt;
the broadcast arcs around it are not theirs. So A and B leave the drawing alone and
change the colour, C to F redraw the bolt itself, and G and H change the composition
and the weight.

| File | What changed |
| --- | --- |
| `a-ink-bolt.svg` | Colours swapped: ink bolt, amber arcs |
| `b-signal-blue.svg` | Blue bolt (`#2F6FD8`), which also echoes the current app icon |
| `c-z-bolt.svg` | Flat terminals turn the bolt into a Z, so it spells the name |
| `d-curved-bolt.svg` | The bolt bent to follow the arcs |
| `e-play-bolt.svg` | The bolt built from two offset play triangles |
| `f-needle.svg` | The bolt narrowed to a tuner needle |
| `g-one-sided.svg` | Arcs on one side only, so the mark points |
| `h-outline.svg` | The bolt as an open outline instead of a solid fill |
